# QACore / red_rider — финальная интеграция

Интерфейс основан на переданном проекте QACore Диаса: сохранены его визуальная структура, переключение темы и языки интерфейса KZ / RU / EN. Серверная часть использует проверенный FastAPI backend red_rider.

## Как связаны части

Фронтенд и API работают на одном адресе и запускаются одним процессом. Отдельный app_server.py, прокси на второй порт и внешняя CDN-сборка не нужны. Настройки модели, диалоги, чек-листы, оценки и апелляции сохраняются сервером в SQLite.

Вызовы оценки обращаются к настроенной модели. Если модель не настроена или ответ некорректен, система сообщает об ошибке. Доказательства ссылаются на исходную нумерацию всех реплик с 1. Итог рассчитывает сервер, с перераспределением веса N/A и округлением до двух знаков.

Решение по апелляции меняет финальную оценку, сохраняя исходную. Для оценки используется снимок версии чек-листа, а не его изменённая задним числом конфигурация.

## Формат сдачи

| Код | Критерий | Вес |
|---|---|---:|
| contact | Установление контакта | 10 |
| discovery | Выявление потребности | 15 |
| identification | Идентификация | 20 |
| consultation | Корректность и полнота | 20 |
| empathy | Эмпатия | 15 |
| dialogue | Ведение диалога | 15 |
| closure | Завершение | 5 |
| critical | Грубые ошибки — отдельный флаг | 0 |

Официальный JSON использует conversation_id, status ok/error, criteria, rationale, evidence_turns, score и фактическую model. Применяется схема 1.0 организаторов.

В переданном QACore-архиве лежали сгенерированные примеры с вымышленными DEV-CHAT/PROD-CHAT ID. Они не используются для сдачи и не переносятся в results/. В комплекте предусмотрено отдельное явно обозначенное демо. Реальные results/dev/results.json и results/prod/results.json создаются только после импорта и обработки соответствующего исходного набора.

DEV содержит 60 чатов и 5 звонков; контрольный набор — 10 чатов, включая записи с ошибками обработки. Экспорт сверяет исходные ID, типы значений, доказательства, баллы, модель, конфигурацию и полноту набора. Флаг critical не обнуляет итог автоматически.

## Запуск

Запустите RUN_WINDOWS.cmd и откройте адрес из строки Application. Скрипт выберет свободный порт, если 8000 занят. Для настоящей оценки заполните подключение модели и API организаторов в настройках. Секреты сохраняются только в локальном .env и не входят в архив.

После экспорта выполните commit и push в свой репозиторий до стоп-кода. Финальный комплект не выполняет публикацию или push автоматически.
